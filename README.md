# Конфигурации Kubernetes

## 2-deployment

Базовая настройка развертывания сервиса Kubernetes в интернете:

1. конфигурация Kubernetes Deployment приложения конвертера изображений (для rollout и репликации)
2. конфигурация Kubernetes Service (для доступа к приложению внутри кластера)
3. конфигурация Kubernetes Ingress на базе nginx (для маршрутизацией трафика с заданного домена (conv.test) на приложение)

## conv_app

Базовая настройка теста сервиса Kubernetes:

1. конфигурация Kubernetes Pod приложения конвертера изображений
2. конфигурация Kubernetes NodePort (для доступа к приложению извне кластера по IP и порту напрямую)
